# Code provenance and licensing

NetContract / LifeAfterCode builds on concepts and reusable components from the earlier ContractCyber project and adds functionality for repository discovery, canonical contract mapping, review workflows, and integrations.

Original project: `grpo8172/ContractCyber` (private GitHub repository). The original repository contains an MIT `LICENSE` with the copyright notice `Copyright (c) 2026 ContractCyber contributors`. The original MIT license text is preserved in this branch.

This attribution identifies the upstream project; it does not assert that every NetContract file came from ContractCyber, that all components are MIT-licensed, or that a private repository is publicly inspectable. Third-party components remain subject to their own licenses. The original repository and its history remain unchanged.

For verification of provenance, the maintainers can provide appropriately redacted commit history or grant controlled access if required by competition organizers.
